iFrame Loader

Load and preview external web pages directly within the dashboard using an embedded frame.

Features
  • URL Loading - Enter any URL to preview it in an embedded frame
  • Quick Links - One-click access to popular developer resources
  • Toolbar Controls - Refresh, open in new tab, copy URL, and close actions
  • Ignore X-Frame-Options - Toggle to bypass X-Frame-Options and CSP frame restrictions via a server-side proxy
  • Error Handling - Clear feedback when a page cannot be embedded
  • Keyboard Shortcut - Press Enter to load, Escape to close
Notes

Some websites block embedding via X-Frame-Options or Content-Security-Policy headers. If a page cannot be loaded, use the "Open in new tab" button to view it directly.
