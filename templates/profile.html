Using Your API Token

Include your token in API requests using one of these methods:

Method 1: X-API-Token Header

curl -X POST 'https://{{ request.host }}/api/webhook-out' \
  -H 'Content-Type: application/json' \
  -H 'X-API-Token: YOUR_TOKEN' \
  -d '{"webhook_id": "my-webhook"}'

Method 2: Authorization Bearer

curl -X POST 'https://{{ request.host }}/api/webhook-out' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -d '{"webhook_id": "my-webhook"}'

Method 3: Query Parameter

curl -X POST 'https://{{ request.host }}/api/webhook-out?api_token=YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"webhook_id": "my-webhook"}'
